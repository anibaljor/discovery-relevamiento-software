# Lean Canvas y Product Vision Board

Herramientas de "una página" para explicitar hipótesis de negocio antes de detallar requisitos. Muy útiles con startups o productos nuevos.

---

## Lean Canvas (Ash Maurya)

Completar en el orden numerado.

```
┌────────────────┬────────────────┬──────────────────┬────────────────┬────────────────┐
│ 2. PROBLEMA    │ 4. SOLUCIÓN    │ 3. PROPUESTA DE  │ 9. VENTAJA     │ 1. SEGMENTOS   │
│                │                │    VALOR ÚNICA   │    INJUSTA     │    DE CLIENTES │
│ Top 3          │ Top 3          │                  │                │                │
│ problemas      │ funcionalidades│ Mensaje claro y  │ Algo que no se │ Clientes       │
│                │                │ convincente      │ copia o compra │ objetivo       │
│ Alternativas   ├────────────────┤                  ├────────────────┤                │
│ existentes     │ 8. MÉTRICAS    │ Concepto de      │ 5. CANALES     │ Early adopters │
│                │    CLAVE       │ alto nivel       │                │                │
│                │                │ ("X para Y")     │ Cómo llegar    │                │
│                │                │                  │ a los clientes │                │
├────────────────┴────────────────┴────────┬─────────┴────────────────┴────────────────┤
│ 7. ESTRUCTURA DE COSTOS                  │ 6. FUENTES DE INGRESOS                    │
│                                          │                                           │
└──────────────────────────────────────────┴───────────────────────────────────────────┘
```

| Bloque | Pregunta guía | Respuesta |
|--------|--------------|-----------|
| 1. Segmentos de clientes | ¿Para quién es? ¿Quiénes son los *early adopters*? | |
| 2. Problema | ¿Cuáles son los 3 problemas principales? ¿Cómo los resuelven hoy? | |
| 3. Propuesta de valor única | ¿Por qué es diferente y vale la pena? | |
| 4. Solución | ¿Cuáles son las 3 funcionalidades clave? | |
| 5. Canales | ¿Cómo llegamos a los clientes? | |
| 6. Fuentes de ingresos | ¿Cómo se gana dinero / cómo se genera valor? | |
| 7. Estructura de costos | ¿Cuáles son los costos principales? | |
| 8. Métricas clave | ¿Qué números indican que funciona? | |
| 9. Ventaja injusta | ¿Qué tenemos que no se pueda copiar fácilmente? | |

## Product Vision Board (Roman Pichler)

| **VISIÓN** — ¿Cuál es tu propósito con este producto? ¿Qué cambio positivo debe generar? |
|---|
| |

| GRUPO OBJETIVO | NECESIDADES | PRODUCTO | OBJETIVOS DE NEGOCIO |
|---|---|---|---|
| ¿Qué mercado o segmento? ¿Quiénes son los usuarios y clientes? | ¿Qué problema resuelve? ¿Qué beneficio aporta? | ¿Qué es el producto? ¿Qué lo hace destacar? ¿Es factible? | ¿Cómo beneficia a la organización? ¿Qué objetivos de negocio cubre? |
| | | | |

---

## Variante para proyectos internos (no comerciales)

Para un sistema interno, reemplazar "ingresos" por **beneficios** (ahorro de horas, reducción de errores, cumplimiento normativo) y "canales" por **estrategia de adopción** (capacitación, comunicación, despliegue por etapas).
